# Java Lab Experiments

This repository contains 15 Java experiments demonstrating basic and advanced Object-Oriented Programming concepts.

1. Classes, Objects, Constructors and Methods
2. Static and Non-static Members, Access Modifiers, Abstraction and Encapsulation
3. Scanner and System Classes for Input and Output
4. Inheritance and Its Types
5. Method Overloading and Overriding
6. Abstract Classes, Interfaces and Dynamic Method Dispatch
7. Built-in and User-defined Packages
8. Exception Handling
9. Multithreading Using Thread and Runnable
10. Synchronization and Inter-thread Communication
11. Thread Lifecycle and Deadlock Prevention
12. Collections Using List, Set, Map and Queue
13. Sorting Using Comparable and Comparator
14. File Handling Using Java I/O
15. Serialization and Deserialization

Language: Java

Purpose: To learn and implement Object-Oriented Programming concepts through practical programs.
